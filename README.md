# S&P 500 RFM Segmentation – 6BUIS017W CWK1

Colab notebook and data for my CWK1 report.

How to run: open CW1_SP500_RFM_21205554.ipynb in Google Colab and click Runtime > Run all.
It loads the saved data from this repo (downloaded 22 Nov 2026), so the results match the report.

Library versions are in requirements.txt.
The CSV files are the saved data and the outputs used in the report tables, and the PNG files are the report figures.
